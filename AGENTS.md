# MiniMe experiment

Keep this a small, single-owner experiment over stock Omnigent. Do not patch
Omnigent, add a daemon, or require Pairflow. Store code and documentation in
English. Keep runtime transcripts and disposable workspaces under ignored
`.runs/`; commit only synthetic, deliberately selected evidence.

The owner authorized local native-agent trials. Agents may edit their assigned
disposable workspace. Do not access email, production stores, deploy, push,
contact anyone, or change machine-wide configuration. Reuse existing local
model authentication. Do not copy credentials into evidence.

Distinguish a controlled protocol exercise, an authored judgment probe,
and observed performance on a real task. Passing one does not prove the others.
